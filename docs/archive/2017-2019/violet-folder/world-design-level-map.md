Source: `violet/World Design - Level Map.text.md`.

This is a mostly linear game, with some player choice of level. The level map shows all playable areas of the world, but there are many parts of the wider galaxy that are not visited in this game. As this is a 2D platformer, traversing each level happens on foot. Traveling between each level happens via space ship. Exploration of each level will happen in real time. The levels are not consistent with each other because each is a different world in the galaxy.
