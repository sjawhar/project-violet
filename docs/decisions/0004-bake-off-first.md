# Run a bake-off before committing to a stack

- **Date:** 2026-09-26
- **Status:** settled

## Decision

After the foundation work, a one-week agent bake-off builds the same slice in several lanes: Godot 2D painted, Godot 3D hybrid, Unity 3D hybrid, Godot flat vector for environments only, and a full-3D protagonist as a control. Sami judges the results.

## Source

Sami chose "Bake-off first" over committing to painted 2D or the 2.5D hybrid immediately.

## Consequences

Engine and art pipeline are not chosen until the bake-off is judged. Foundation work stays engine-neutral.
