# Target a commercial Steam release

- **Date:** 2026-09-26
- **Status:** settled

## Decision

Violet is built as a polished commercial game for Steam. The first milestone is a vertical-slice demo.

## Source

Sami chose "Commercial Steam release" when asked what the studio is building toward.

## Consequences

It sets the quality bar for every pipeline and brings Steam's AI-content disclosure with it. It rules out a free or jam-scale release as the target.
