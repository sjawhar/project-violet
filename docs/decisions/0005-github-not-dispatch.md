# Track work on GitHub, not Dispatch

- **Date:** 2026-09-26
- **Status:** settled

## Decision

Specs live in GitHub issue bodies, changes land through pull requests, and asset approval happens on those pull requests.

## Source

"should we use dispatch for this? I think I'd rather not. Can't we just use github?"

## Consequences

Dispatch is not used for this project. Asset previews use inline PR images plus a GitHub Pages review gallery.
