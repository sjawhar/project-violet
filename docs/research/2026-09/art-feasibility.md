# Violet Art Pipeline: Can Agents Deliver D, A, or C? (2026-09-26)

## 1. Verdict

**High confidence: D fails for the protagonist. Moderate confidence: D's environments alone are viable with heavy human curation. High confidence: A is achievable via a specific rig-based workaround, not via "AI paints the animation." C is the easiest track for environments and color-tagging, but inherits A's character-rig gap.**

Per Sami's ruling ("D if agents can do it, otherwise A. C is also reasonable"): **the evidence says A, with C as a legitimate co-favorite for a flatter tone.** The hardest asset — an expressively rigged, animated 3D protagonist (run/jump/dash/stomp/double-jump/idle/land + scarf secondary motion) — has **zero verified example anywhere** (commercial, jam, or research) of an LLM agent producing it end-to-end. Two independent lines of evidence converge on this: (1) the only rigorous LLM-Blender benchmark, BlenderGym (arXiv 2504.01786), doesn't even test rigging/animation and shows SOTA VLMs losing to humans on *easier* static tasks; the flagship LLM-Blender research system, LL3M (arXiv 2508.08228), only ever generates static props. (2) Every commercial-scale attempt to ship AI-generated 3D *character* art was caught immediately: *Vapor World: Over The Mind* swapped in AI cutscene character art pre-launch, couldn't hold the model consistent across shots, went "mostly negative," and the studio reverted within days (PC Gamer, 2026-08-24). *Clair Obscur: Expedition 33* — the highest-bar comparison game in this research — tried AI, "didn't like it," and shipped 100% human art.

D's 3D-generation and environment-dressing story is much better: Meshy/Tripo P2.0/Rodin Gen-2.5/TRELLIS.2 are real, priced, API-scriptable, and blender-mcp (29,424★, MIT) lets an agent drive Blender headlessly for geo-nodes scattering and toon-shader graphs — genuinely agent-strong, mechanical, deterministic work. But no vendor demonstrates push-button *style consistency* across a 30-50-piece modular kit, let alone six biomes' worth — every source frames that as needing a human art director's harmonization pass.

A's character problem is real too — no source anywhere shows a verified 8-12-frame consistent walk/run cycle from any image model (Nano Banana Pro's own documented failure mode, dated 2026-03-07, is "proportions might be slightly different between sheets"). But A has a genuine escape hatch D lacks: **rig-based cutout animation**, where the image model paints exactly *one* static pose per body-part layer (torso/limb/head/scarf — never multiple poses of the same part), and a skeletal rig (Spine) handles all actual motion procedurally. This sidesteps the consistency problem by construction. It is concretely demonstrated: **GenieLabs' `spine-animation-ai`** (480★, 69 forks, active CI, MIT-adjacent) is a working, open-source Claude Agent Skill that auto-positions parts (SIFT+RANSAC), builds Spine skeleton JSON, and generates idle/walk/run/jump animations with zero GUI dragging — the single strongest piece of "agents can actually do this" evidence found in the entire investigation, across all three tracks.

C is technically the cleanest track for environments (Recraft's native SVG + "Style Lock" is well-evidenced and API-batchable) and clearly the cheapest to color-tag (SVG is already a DOM), but its character path collapses back onto A's: Spine explicitly refuses SVG import (forum/roadmap-confirmed), so a vector character must be rasterized before rigging anyway.

## 3. Failure Modes / Gaps

1. **The rigging/animation gap is the load-bearing finding.** Every 3D pipeline surveyed (generation, auto-rig, motion libraries, text-to-motion research) stops at generic idle/walk/run. Nothing — commercial or open-research — has a linked demo of dash, ground-pound, or double-jump. This is a human-animator-required gap independent of which engine or generator is used.
2. **AI-character-consistency backlash is a demonstrated commercial risk, not a hypothetical.** *Vapor World*'s reversal happened in days. Steam's Jan 2026 disclosure rewrite plus aggregate stats (AI-disclosed titles average lower review volume) mean shipping visibly-inconsistent AI character art is a business risk, not just an aesthetic one.
3. **Style consistency across a modular biome kit is unsolved by any vendor** — Recraft's "Style Lock" and Meshy/Tripo's prompting are the closest tools, but no source shows 30-50 assets (let alone 6 biomes) verified consistent without a human curation pass.
4. **Devbox-specific tooling gaps:** Cascadeur is officially Linux-supported only on Ubuntu 20.04-22.04, not Pop!_OS 24.04; TRELLIS.2 needs a CUDA GPU this AMD-iGPU devbox doesn't have (cloud rental required); AccuRIG is Windows-only.
5. **Search-result hygiene risk:** several sub-searches surfaced fabricated-sounding tool/paper names (e.g., a nonexistent "BlenderRAG" standalone paper) from SEO-farm aggregation. Every claim in this report traces to a primary source (vendor doc, GitHub, arXiv, or named journalism) re-verified where flagged.

## 4. Bake-Off Tasks (agent-executable, ≤1h Sami-judging total)

| # | Task | Pass | Fail |
|---|---|---|---|
| 1 | **A-track character.** Agent paints one reference pose per body-part layer (torso/limb/head/scarf) via an image model, then runs a Spine (or Godot Skeleton2D) auto-rig script (`spine-animation-ai` pattern) to produce idle/run/jump/dash/stomp/double-jump/land + scarf secondary motion, output as an HTML5/video preview. | Identity/proportions match across all parts (no drift, since each part was painted once); motion shows weight/anticipation/follow-through; scarf visibly lags the torso. Sami judges one preview, <10 min. | Any part's style/proportions mismatch, or motion reads as robotic/floaty with no timing craft. |
| 2 | **D-track character (control test).** Agent attempts the same moveset via Meshy/Tripo generation + blender-mcp rigging + Cascadeur-assisted or text-to-motion animation. | Same criteria as #1. | Given the research finding above, this is expected to fail or require heavy manual keyframing — the point is confirming or overturning that expectation cheaply. |
| 3 | **Biome kit consistency.** Agent generates one full biome's modular kit (~15-20 pieces: walls/props/foliage/rock) via (a) Recraft SVG batch and (b) Meshy/Tripo 3D, same prompt discipline both times. | A same-biome asset grid reads as one coherent set (bevel language, palette, proportions) on sight, <10 min review; imports into engine error-free. | Visibly mismatched styles within the same biome, or import/topology errors. |
| 4 | **Color-tag author + verify.** Agent tags a small test scene across all three mechanisms (SVG `data-resonance-color` attribute; Spine slot-naming convention; Blender custom property → Godot `global uniform`), writes one validator script per track, then Sami (or the agent) deliberately deletes one tag and reruns. | All three validators run clean on the tagged version and correctly fail on the mutated one; Sami can read each validator script and confirm the logic in <15 min total. | Any validator passes the mutated (missing-tag) version, or requires GUI inspection instead of a script. |

**Interpretation:** ≥3/4 pass → proceed with A (or C for environments) with confidence; task 1 passing alone is the single decisive signal, since it is the asset the whole ruling hinges on. Task 2 passing would be a genuine surprise worth escalating immediately, since it contradicts every piece of evidence gathered.

## 5. Costs (representative monthly, indie scale)

- **Image gen:** Gemini 3/3.1 (Nano Banana Pro) via API — per-image, low ($ cents); GPT-Image-2.5 Flare/Sunburst — OpenAI API pricing, per-image; FLUX.1 Kontext [dev] free self-host / [pro] paid API.
- **3D gen (if pursuing D's environments):** Meshy Pro $20/mo (≈100 assets) to Ultra $100/mo; Tripo Pro ~$19.90/mo; Rodin Creator $24/mo (fewer, higher-fidelity hero pieces); TRELLIS.2 free weights + cloud GPU rental (H100/4090, hourly).
- **Vector gen:** Recraft $0.05-0.12/image via API, or Basic plan $10-12/mo.
- **2D rig:** Spine Essential $69 one-time (Professional $379) — cheapest tool in the whole stack; `spine-animation-ai` itself is free/open-source (PolyForm NC).
- **3D animator-assist:** Cascadeur Indie $8-19/mo (rev <$100k) — but needs Ubuntu 20.04-22.04 specifically, not this devbox's Pop!_OS, so a secondary machine or VM is a real added cost/friction.
- **Steam disclosure:** free (Steamworks Content Survey), but per Valve's 2026-01-17 rewrite, any shipped AI-generated player-facing art must be disclosed in free-text on the store page regardless of which track is chosen.
- **Human-in-loop fallback (if agents can't close the gap):** Kaedim $400-1,200/mo for a handful of complete 3D assets — priced as a signal of what "AI+human QA" actually costs when agents alone don't clear the bar; useful ceiling reference, not recommended given it doesn't answer the agents-alone question.
