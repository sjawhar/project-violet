Each lane ran the glow-up rounds in docs/bakeoff/glow-up.md: fix one gap, shoot the same four moments of the fixed replay, have a critic compare the new round with the latest kept round blind, and revert the round if it is worse on an axis and better on none. Every row below shows the 40 s still; each row links its 5, 20, 40 and 60 s stills. The full set of 132 stills is here. The preliminary judging page from before the rounds is here.

Read these first.
  • The critic was the same model as the workers. All 33 critiques (11 per lane) ran on Anthropic Claude Opus 5.5, the same model as the agents doing the work. The rules ask for a critic from a different model family. So every score and every keep-or-revert call on this page is Claude judging Claude's work. The comparisons were blind: neutral file names and a random A/B order.
  • These worlds still show the original cutout Violet (the rig from #28). Her new frame-by-frame art is not in them.
  • Frame time on the Radeon 890M: not measured. It waits on the ask in issue #4. Nothing on this page estimates it.
  • Final judging captures: not taken yet. The stills are the glow-up's own fixed shots, rendered in software on oryx.
  • Scores are 1 to 5 against GRIS and Planet of Lana, as visual quality / character appeal / color readability. A fresh critic scored each round, and scores drift about a point between critics. The verdict (better, worse or the same on each axis) is the steadier signal.
  • Every image was checked: its sha256 matches the Git LFS pointer on the lane branch at the commit named. The hashes are in glow-up-data.json.
